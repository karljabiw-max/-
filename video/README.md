# Vibe知识大赏 ·《不》

**两岁的孩子，为什么总说「不」？** / *Why Two-Year-Olds Say No*

无旁白、双语字幕、配乐由代码合成。全片 1920×1080 / 30fps / 2:15，画面完全由 `index.html` 里的 Canvas 代码逐帧画出。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 全片动画：`window.render(t)` 只由时间 t 决定；浏览器直接打开可循环预览 |
| `scripts/render.mjs` | Playwright 逐帧截图，分 4 段并行，直接管道进 ffmpeg |
| `scripts/bgm.py` | numpy 合成配乐（77 BPM，A 小调，段落对齐分镜） |
| `scripts/fetch_fonts.sh` | 下载 Noto Sans SC / Noto Serif SC / EB Garamond 到 `fonts/` |
| `output/bu.mp4` | 成片 |

## 重新生成

```bash
bash scripts/fetch_fonts.sh
NODE_PATH=$(npm root -g) node scripts/render.mjs --out build/video.mp4      # 画面
python3 scripts/bgm.py build/bgm.wav                                        # 配乐
ffmpeg -i build/video.mp4 -i build/bgm.wav -af loudnorm=I=-14:TP=-1 \
  -c:v copy -c:a aac -b:a 192k -shortest output/bu.mp4                      # 合成
```

只看几张静帧：`node scripts/render.mjs --stills 6,30,46,75 --outdir build/stills`

## 事实核对

- Gallup, G. G. (1970). Chimpanzees: Self-Recognition. *Science* 167(3914), 86–87. 黑猩猩麻醉后在眉骨处染色，醒后照镜子会去摸标记。
- Amsterdam, B. (1972). Mirror self-image reactions before age two. *Developmental Psychobiology* 5(4), 297–305. 一岁前后多把镜像当作玩伴，20–24 个月组多数能认出自己。片中只说「多数」，没给具体百分比。
- Erikson, E. H. (1950). *Childhood and Society*. 第二阶段「自主 vs 羞怯怀疑」，常见年龄范围约 18 个月–3 岁，对应品质为「意志」(will)。
- 发脾气比例：不同研究给出的 18–24 个月幼儿发脾气比例约 70%–87%（Potegal & Davidson 2003 等），片中按区间写。
- 词汇增长：18→24 个月产出词汇大幅增长，常见为数倍（Fenson et al. 1994，CDI 常模）；个体差异很大，片中曲线标注「示意」。
- 前额叶晚熟：Gogtay et al. (2004) *PNAS* 显示前额叶是皮层中最晚成熟的区域之一，常被概括为「二十多岁才成熟」。
